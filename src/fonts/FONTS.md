# Fontes

Este projeto usa duas famílias tipográficas da identidade Kairós, ambas sob a
**SIL Open Font License 1.1** (livre para uso e redistribuição):

- **Playfair Display** — títulos e editorial. https://fonts.google.com/specimen/Playfair+Display
- **Inter** — texto, UI e rótulos. https://fonts.google.com/specimen/Inter

Arquivos `.ttf` são as versões variáveis obtidas do repositório oficial Google Fonts.
