# Apresentações comerciais

| Pasta | Conteúdo |
|---|---|
| `jp-aluminios/` | Apresentação institucional da JP Alumínios (7 páginas) |
| `checkmate-liqsy/` | Portfólio Checkmate + Liqsy com fichas técnicas de drinks (9 páginas) |
| `motor/` | Motor compartilhado: a partir de uma definição de páginas gera PDF, PDF leve, PPTX editável e JPGs |

Cada projeto tem `fonte/build.py` (para gerar de novo) e `entregas/` (arquivos prontos para enviar).
