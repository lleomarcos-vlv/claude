Google Places API

Como criar e proteger a chave
  1. Acesse console.cloud.google.com, crie um projeto e ative o faturamento.
  2. Em "APIs e serviços", ative a Places API (New).
  3. Em "Credenciais", crie uma chave de API.
  4. Restrinja a chave: em "Restrições de API", deixe só a Places API (New).
  5. Em "Cotas", defina um limite diário de requisições para não ter surpresa na fatura.
  6. Se for abrir o painel por http://localhost, restrinja também por referenciador HTTP.
