Como isso funciona

Este arquivo é um agente completo em HTML+JS puro: sem servidor, sem build, sem dependência. Ele monta o prompt de sistema, conversa com a API do provedor escolhido direto do navegador (streaming), separa o bloco de código da explicação, e mantém o contexto para você pedir ajustes em cima do mesmo script. A chave de API fica só no localStorage da sua máquina — nunca é enviada para outro lugar além do provedor. Use chave pessoal e não publique este arquivo com a chave preenchida.
